# AIXD - AI & Experience Design

**Expand Your Human Potential With AI**

A practical hub for experience designers learning to shape experiences with artificial intelligence.

## What is AIXD?

AIXD (AI & Experience Design) is for anyone who identifies as an experience designer and wants to learn how to expand their human potential with AI—using AI in all the ways they can to shape experiences.

### Our Philosophy

In 2025, we've moved beyond the AI hype. This isn't about AI replacing designers—it's about:

- **Augmentation, not replacement**: AI as a tool to enhance your creative process
- **Practical application**: Real ways to use AI across your entire design workflow
- **Human potential**: Automate the mundane so you can focus on meaningful work
- **Community learning**: Share experiments, patterns, and discoveries together

## What You'll Find Here

### 🛠️ Essential AI Tools
Curated tools for designers: ChatGPT, Claude, Figma AI, Galileo AI, and more—with practical use cases for each.

### 🎨 AI-Native Design Patterns
Beyond chat interfaces: adaptive UIs, refinement controls, task-oriented interfaces, multimodal interactions, and more.

### 📚 Learning Resources
From AI literacy fundamentals to advanced prompting techniques and case studies.

### 🤝 Community
A space to share experiments, contribute patterns, and connect with other designers exploring AI.

## Technology Stack

- **Next.js 14** with App Router
- **TypeScript** for type safety
- **Tailwind CSS** for styling
- **Static Export** for easy deployment

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to see the site.

### Build

```bash
npm run build
```

This creates a static export in the `out/` directory, ready to deploy to any static hosting service.

## Deployment

This site is configured for static export and can be deployed to:

- **Vercel**: `vercel --prod`
- **Netlify**: Drag and drop the `out/` folder
- **GitHub Pages**: Upload the `out/` folder contents
- **Any static hosting**: The `out/` folder contains all static assets

### Deploying to AIXD.org

1. Build the site: `npm run build`
2. The `out/` directory contains your static site
3. Upload to your hosting provider or use their CLI tools
